Одинаковый результат — разные причины

Два менеджера выполнили план продаж на 75%. Вам предстоит выяснить, почему это произошло, и выбрать решения для каждого сотрудника.

  1. Оцените первоначальный вывод руководителя.
  2. Изучите рабочие данные обоих менеджеров.
  3. Разделите обнаруженные факты на три части: человек, ситуация, система.
  4. Примите управленческие решения с учётом результатов проверки.

После проверки можно исправлять ответы. При переходе между этапами результаты сохраняются.
